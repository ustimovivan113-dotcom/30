# LMS — платформа онлайн-обучения

Django + DRF проект с курсами, уроками, авторизацией по email и оплатой курсов через Stripe.

## Основной функционал

- Регистрация / авторизация по email
- CRUD курсов и уроков
- Оплата курсов через Stripe Checkout (тестовый режим)
- Документация API через drf-yasg (Swagger + ReDoc)
